GDI+ Memory Leak Fix - Anleitung
=================================

PROBLEM:
--------
Der Fehler "System.Runtime.InteropServices.ExternalException (0x80004005): Allgemeiner Fehler in GDI+."
tritt auf, weil CreateRoundRectRgn() GDI-Handles (HRGN) erstellt, die nie freigegeben werden.

Nach mehrmaligem Öffnen/Schließen von Forms sind die GDI-Ressourcen erschöpft.

LÖSUNG:
-------
1. DeleteObject DllImport hinzufügen
2. Nach Region.FromHrgn() das HRGN-Handle mit DeleteObject() freigeben

BETROFFENE DATEIEN:
-------------------
- Form\CreatePaymentForm.cs (Zeile 93, 768-769)
- Form\AbrechnungForm.cs (mehrere Stellen, Zeile 4558)
- Form\AbrechnungForm_alt.cs (Zeile 445, 681, 1241)

SCHRITT 1: DeleteObject Import hinzufügen
------------------------------------------
In jeder Datei, die CreateRoundRectRgn verwendet, füge nach dem Import hinzu:

[DllImport("gdi32.dll", SetLastError = true)]
private static extern bool DeleteObject(IntPtr hObject);

SCHRITT 2: Region-Erstellung korrigieren
-----------------------------------------
VORHER (FALSCH - Memory Leak):
try { Region = Region.FromHrgn(CreateRoundRectRgn(0, 0, Width, Height, 24, 24)); } catch { }

NACHHER (RICHTIG):
try 
{ 
    IntPtr hRgn = CreateRoundRectRgn(0, 0, Width, Height, 24, 24);
    Region = Region.FromHrgn(hRgn);
    DeleteObject(hRgn);  // <-- WICHTIG: Handle freigeben!
} 
catch { }

ALTERNATIVE SCHREIBWEISE (bei mehreren Verwendungen):
------------------------------------------------------
private static void SetRoundedRegion(Control control, int radius)
{
    if (control == null) return;
    try
    {
        IntPtr hRgn = CreateRoundRectRgn(0, 0, control.Width, control.Height, radius, radius);
        if (hRgn != IntPtr.Zero)
        {
            control.Region = Region.FromHrgn(hRgn);
            DeleteObject(hRgn);
        }
    }
    catch { }
}

Verwendung:
SetRoundedRegion(this, 24);
SetRoundedRegion(btnManuellAdd, 12);
SetRoundedRegion(_cardAbrechnen, 18);
